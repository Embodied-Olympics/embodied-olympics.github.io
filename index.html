ro-live

ro-live is a small tool that streams Embodied Olympics matches live. Embodied Olympics is a benchmark where AI agents control simulated robots in sports. The matches are computer simulations, and the pictures are rendered.

The tool uses the YouTube Data API to schedule, start and end live streams on the owner's own YouTube channel, to read the stream health, and to upload short edited films of finished matches to that channel.

Only the channel owner uses this tool. It does not ask other people to sign in.
